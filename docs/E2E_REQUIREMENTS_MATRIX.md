# E2E requirements matrix

This matrix prevents a passing browser suite from being mistaken for coverage of functionality that has not been implemented. A requirement is “covered” only when an independently diagnosable Playwright journey exercises its observable acceptance criteria.

| `FR-001`              | Create, list, view and edit an activity with dates, location, funding, participant target and curriculum attachment             | `frontend/e2e/activity-setup.spec.ts`: AM creates an activity with a curriculum, views its recorded filename and edits it                       | Covered for the implemented activity-setup slice       |
| `FR-002`              | Nomination invitation recording to CNUs                                                                                         | `frontend/e2e/activity-setup.spec.ts`: selects a CNU and sends a nomination invitation from the created activity                                | Covered for the implemented invitation slice           |
| `SEC-003`             | Synthetic sign-in, role session, sign-out and invalid credentials                                                               | `frontend/e2e/activity-setup.spec.ts`: each fixture profile signs in/out; invalid credentials are denied                                        | Covered for synthetic mode                             |
| `FR-022`              | All identified profiles authenticate, receive scoped sessions and sign out                                                      | `frontend/e2e/activity-setup.spec.ts`: full fixture profile browser matrix and sign-out; API integration test independently covers all fixtures | Covered                                                |
| `FR-023`              | Activity list ordering and pagination                                                                                           | `frontend/e2e/activity-setup.spec.ts`: changes ordering and navigates activity pages                                                            | Covered for the implemented dashboard slice            |
